# V11 图片素材目录

此目录用于《郑成功收复台湾》V11 网页视觉素材替换。

- `characters/`：人物主视觉
- `event/`：公共事件横幅
- `battlefields/`：五大战场场景图
- `cards/`：卡牌插画
- `icons/`：后续 UI 图标

图片副档统一使用 JPG。
